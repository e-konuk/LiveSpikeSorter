# Live Spike Sorter (LSS)

Live Spike Sorter (LSS) is a GPU-accelerated real-time spike sorter for extracellular neural recordings. It streams data from [SpikeGLX](https://billkarsh.github.io/SpikeGLX/), matches incoming signals against spike templates generated by [Kilosort4](https://github.com/MouseLand/Kilosort), and outputs sorted spike events with low latency. The sorted output can drive closed-loop neurofeedback experiments via built-in networking, and built-in processors, including a logistic-regression decoder, can classify neural activity in real time.

> **Recommended before your first experiment:** do a full offline test run. Replay a
> recording you already have through a SpikeGLX simulated probe, so the entire pipeline
> runs exactly as it would on the rig with no hardware attached. The
> [Offline Sorting Guide](OfflineSortingGuide.md) covers first-time machine setup and
> the per-session workflow.

## Python Setup

Install an Anaconda distribution of Python, then from your repository root:

```bash
conda env create -f environment.yml
conda activate lss
```

This installs Python, PyTorch (CUDA 11.8 build), Kilosort 4.0.13, and the CUDA 11.8 / cuDNN 8.9.7 libraries LSS runs on, so no separate CUDA or cuDNN install is needed.

Update an existing environment with:

`conda env update -f environment.yml --prune`.

## Installing LSS

Download `LiveSpikeSorter-vX.Y.Z-win64.zip` from the [Releases](../../releases) page and extract it into `<repo>\bin\`, so that you have `<repo>\bin\LiveSpikeSorter.exe`. Use the release that matches your checkout (`git checkout vX.Y.Z`); the launcher warns if the exe and the repository versions differ.

## Running LSS 

From the `lss` environment, in any directory:
```bash
lss
```

(`environment.yml` installs the `lss` command from this checkout. In an environment created before it existed, run `conda env update -f environment.yml --prune` once, or `python src/Python/run_lss.py` still works.)

The GUI lets you configure one or more sorter instances, select Kilosort output directories, and optionally re-run Kilosort4 before launching LSS. You must run Kilosort4 on a short recording (10–20 minutes) to generate templates, the whitening matrix, drift matrices, and other tensors that LSS needs at runtime.

## Building from Source

Only needed if you change the C++/CUDA code.

1. Install Visual Studio 2022 (Build Tools, `v143` toolset), then the [CUDA 11.8 toolkit](https://developer.nvidia.com/cuda-11-8-0-download-archive). Install CUDA after Visual Studio so it registers its build integration, and check that `CUDA_PATH` points to it (e.g. `C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v11.8`).  
2. cuDNN comes from the `lss` environment. Point the build at it and open the solution from an activated prompt (or set `CUDNN_PATH` permanently as a user environment variable):

   ```bash
   conda activate lss
   set CUDNN_PATH=%CONDA_PREFIX%\Library
   devenv LiveSpikeSorter.sln
   ```

3. Select **Release | x64** and build the solution.  
4. If successful, you should see output in `<repo>\x64\RELEASE\LiveSpikeSorter.exe`. The launcher uses this build over `bin\`; set `LSS_EXE` to use an exe somewhere else.

Releases are built by `.github/workflows/release.yml` when a `v*` tag matching the `VERSION` file is pushed.

## Real-Time Output

The SDM (Stimulus Display Machine) integration sends a per-bin summary of spiking to a separate machine for closed-loop stimulus control. What gets sent depends on the processor selected in the launcher: 

1. Z-score firing trigger 
2. Logistic regression decoder trained on a previous session's `spikeOutput.txt` and event file
3. Raw per-neuron bin counts (TCP)
4. FS/RS custom stimulus trigger (used in our paper's closed-loop demo experiment). 

All except bin counts are sent over UDP. Overall functionality is limited.

For other custom use cases, the spike streams can be networked via UDP, configurable under "Spike Stream" in the launcher. When enabled, each sorted spike is sent as soon as its batch is processed. A receiver can parse these packets using your preferred interface ([Python example](src/Python/lss_receiver.py)).
